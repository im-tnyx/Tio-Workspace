# 📦 Completed task archive

[← AI context](../README.md) · [Task lifecycle](../tasks/README.md)

Store **completed, verified** task records here under `.ai/archive/<year>/`. Do not create an empty year folder.

A record can be archived only after:
1. GitHub confirms the applicable PR is merged or the approved objective is otherwise explicitly completed.
2. Changed files and validation evidence have been reconciled with the live repository.
3. Post-merge checks and any required follow-ups are recorded.
4. [`current.md`](../current.md) no longer points to that task.

Archives are historical handoff evidence, not a source for current project state; never preload or scan the archive during session startup. The canonical docs and live GitHub history always take precedence.

**Do not copy Tio Ledger's task history here:** its completed work belongs to a different product and technology stack.
